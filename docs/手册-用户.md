# ORIN 用户手册

本文档面向 ORIN 平台的普通用户，介绍智能体对话、工作流使用与知识库检索。

---

## 1. 快速入门

### 1.1 登录

1. 访问 <http://localhost:5173>
2. 输入用户名和密码（由管理员分配）
3. 首次登录后建议进入"我的 API Key"设置访问密钥

### 1.2 角色与默认页面

| 角色 | 默认进入 |
|------|----------|
| 普通用户（ROLE_USER） | ORIN Chat（`/chat`）— 智能体对话与服务入口 |
| 管理员（ROLE_ADMIN） | 管理台首页（`/dashboard/control/admin-overview`） |

> 当前首版权限矩阵只保留两类角色：`ROLE_ADMIN` 与 `ROLE_USER`。运维 / 平台 / 超管等历史角色已合并到管理员或下线，详见 [角色矩阵.md](./角色矩阵.md)。

---

## 2. 智能体对话（ORIN Chat）

### 2.1 进入 ORIN Chat

登录成功后默认进入 `/chat`，或在顶栏点 **对话 → ORIN Chat**。

### 2.2 与智能体对话

1. 在侧边栏点 **新对话**（或选中一个已有会话）
2. 在输入框输入问题，按 `Enter` 发送；`Shift+Enter` 换行
3. 智能体的回复会逐段流式渲染到对话区

### 2.3 切换智能体

如果接入了多个智能体，点侧边栏 **服务** 按钮，在列表里选一个即可。当前智能体支持的能力（工具 / MCP / 知识库）会在首页 / 对话标题旁显示。

### 2.4 多轮对话与上下文

智能体支持多轮对话，能记住同一会话内的上下文。如果要开始新话题，点侧边栏的 **新对话**。

### 2.5 刷新后仍能看到上次会话

最近一次选中的智能体与最近一个会话会保存在浏览器本地，刷新或重新打开浏览器后会自动恢复。失效的会话（被管理员删除）会被自动清掉。

## 3. 工作流与协作

ROLE_USER 当前不开放工作流 / 协作入口，需要使用请联系管理员开通权限。

## 4. 知识库检索

### 4.1 在 ORIN Chat 内使用参考资料

在 `/chat` 输入框上方点 **参考资料** 标签，勾选要纳入回答的知识库。该选择会随会话持久化，刷新后仍在。

### 4.2 联系管理员获取知识库

如果你需要的知识库没出现在选择器里，说明管理员还没把它发布给你。请联系管理员添加 / 发布后即可在参考资料面板里看到。

## 5. API Key 管理

### 5.1 普通用户自助入口

访问 <http://localhost:5173/platform>

### 5.2 创建 API Key

1. 进入 API Key 管理页面
2. 点击"创建密钥"
3. 填写密钥名称，选择有效期
4. **复制密钥**（只显示一次）
5. 将密钥用于 API 调用

### 5.3 使用 API Key

```bash
# 示例：查询可用的 Agent
curl http://localhost:8080/api/v1/agents \
  -H "Authorization: Bearer sk-orin-your-key-here"
```

### 5.4 管理密钥

- **禁用密钥**：临时关闭某个密钥的访问权限
- **启用密钥**：重新开放已禁用的密钥
- **删除密钥**：永久删除（无法恢复）

## 6. 常见问题

### Q: 无法登录

- 检查用户名和密码是否正确
- 联系管理员确认账户状态
- 清除浏览器缓存后重试

### Q: 智能体回复很慢

- 可能 AI Engine 在处理复杂任务，请稍等
- 如果长时间无响应，检查 AI Engine 是否在线

### Q: 工作流执行失败

- 检查输入参数是否完整
- 查看错误信息中的 `traceId`
- 联系管理员或查看[手册-管理员.md](./手册-管理员.md)中的告警处理

### Q: 知识库检索无结果

- 确认知识库已同步完成（在知识资产页面查看状态）
- 尝试更换关键词或使用更简洁的表述
- 确认该知识库已接入你的智能体
