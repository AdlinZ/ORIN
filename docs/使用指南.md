# ORIN 使用指南

面向使用者：从哪里进入功能、联调时先看什么、如何快速验证。

## 2. 主导航

前端按 **chat / workspace / admin 三产品面**组织入口；菜单在 `orin-frontend/src/router/topMenuConfig.js` 通过 `surface` 字段分组，再按 `roles` 过滤可见性。判断"主入口"时，以角色可见菜单为准；`ROUTES` 常量里的落地页路径和历史重定向路径不能单独当作菜单入口。

### 2.0 三产品面入口

| 产品面 | canonical | 历史路径（仍可用） | 面向对象 | 核心职责 |
|---|---|---|---|---|
| ORIN Chat | `/chat` | — | 普通使用者 | 对话、文件处理、知识问答；只暴露个人资源 |
| ORIN 工作台（workspace） | `/workspace` | `/dashboard/applications/*`、`/dashboard/resources/*` | 创作者、开发者、业务操作人员 | 我的智能体、工作流、协作、知识库、扩展能力、运行记录 |
| ORIN 管理台（admin） | `/admin` | `/dashboard/control/*`、`/dashboard/runtime/*` | 平台管理员 | 组织权限、模型、Provider、网关、配额、审计、监控与系统配置 |

菜单是否可见不等于能力已经完整闭环；菜单渲染仅做角色门，最终可操作性由后端 ACL 决定。

### 2.1 工作台菜单（workspace）

| 分组 | 主路径 | 覆盖能力 |
|---|---|---|
| 智能体 | `/workspace/agents` | 工作台、列表、会话 |
| 工作流与协作 | `/workspace/workflows`、`/workspace/collaboration/workflows` | 工作流中心、可视化编排、执行记录、多智能体协同 |
| 知识库 | `/workspace/knowledge/center` | 知识中心、知识资产、检索实验 |
| 扩展能力 | `/workspace/extensions` | Skills、MCP、模型工具绑定 |

### 2.2 管理台菜单（admin，仅管理员可见）

| 分组 | 主路径 | 覆盖能力 |
|---|---|---|
| 平台控制 | `/admin` | 用户、部门、模型、定价、环境、通知、数据资产、MCP、统一网关 |
| 运行观测 | `/admin/runtime` | 监控总览、服务器、任务队列、调用链路、用量、性能、告警日志 |

### 2.3 Chat 菜单（chat，普通用户）

| 分组 | 主路径 | 覆盖能力 |
|---|---|---|
| 对话 | `/chat` | ORIN Chat 单页应用（侧边栏「服务 / 新对话 / 最近对话 / 文件 / 个人中心 / API Key 自助」） |

历史 `/portal` 重定向到 `/chat`，`/portal/api-keys` 重定向到 `/platform/api-keys`。`/platform` 仍保留作为 `/admin` 之外的 API Key 自助入口，由 `ROLE_USER` 直接访问。

## 2.1 角色入口

| 角色 | 默认入口 | 说明 |
|------|----------|------|
| `ROLE_ADMIN` | `/admin/admin-overview` | 可进入管理台与工作台，两者导航独立 |
| `ROLE_USER` | `/chat` | 可进入 Chat 与本人资源范围的工作台，不可进入管理台 |

前端当前按三条产品线组织入口：

| 入口 | 产品面 | 面向对象 | 说明 |
|---|---|---|---|
| `/` | 官网 | 访客 | 官网、产品介绍、GitHub 与入口分发 |
| `/chat` | chat | 普通用户 | 智能体对话、知识问答、文件处理与 AI 创作 |
| `/workspace`（历史 `/dashboard/applications/*`、`/dashboard/resources/*`） | workspace | 创作者 / 开发者 / 业务操作人员 | 我的智能体、工作流、协作、知识库、扩展能力 |
| `/admin`（历史 `/dashboard/control/*`、`/dashboard/runtime/*`） | admin | 管理员 | Agent、模型、知识库、Workflow、MCP、监控、权限与审计 |
| `/platform` | workspace 子入口 | 开发者 / API 调用方 | 个人 `CLIENT_ACCESS` Key、调用历史、MCP 配置与 API 文档入口 |
| `/register` | chat 注册 | 个人用户 | 自助创建 `ROLE_USER` 账号；注册后默认进入 `/chat` |

历史 `/portal` 会重定向到 `/chat`，`/portal/api-keys` 会重定向到 `/platform/api-keys`。

角色边界详见 [角色矩阵.md](./角色矩阵.md)。直接输入不可见模块 URL 时，路由守卫会按同一角色矩阵拦截。

### 3.5 ORIN Chat（普通用户）

ROLE_USER 登录后默认进入 `/chat`；可通过产品切换器进入 `/workspace` 管理本人资源，但不会看到 `/admin` 管理台入口。

| 要做的事 | 从哪里进入 |
|----------|------------|
| 进入 ORIN Chat | `/chat` |
| 切换智能体 | 侧边栏「服务」按钮 → 选中目标智能体 |
| 新建会话 | 侧边栏「新对话」按钮 |
| 上传文件 | 输入框左侧「+」图标 |
| 查看最近对话 | 侧边栏「最近对话」 |
| 调整参考资料范围 | 首页 / 对话中「参考资料」标签 |
| 管理个人资料 | 头像菜单 → 「个人中心」跳到 `/chat/profile` |
| 自助 API Key | 头像菜单 → 「API Key 自助」跳到 `/platform` |
| 管理本人资源 | 产品切换器 → 「ORIN 工作台」跳到 `/workspace` |
| 退出登录 | 头像菜单 → 「退出登录」 |

> ROLE_USER 访问历史 `/dashboard/applications/*`、`/dashboard/resources/*` 时会重定向到有权访问的 `/workspace/*` canonical 路径；访问 `/dashboard/control/*`、`/dashboard/runtime/*` 或 `/admin/*` 时会被路由守卫拦截并回到 `/chat`。管理员视图、运行监控、系统设置等后台入口对普通用户不可见。

### 3.6 个人用户自助注册

访问 `/register` 可创建个人账号。注册成功后后端会写入 `sys_user` 与 `sys_user_role`，默认角色为 `ROLE_USER`，响应 JWT 会携带 `roles=["ROLE_USER"]`，前端直接进入 `/chat`。如果该用户名下没有智能体，后端会在加载服务列表时自动创建一个本人可见的“默认助手”兜底入口；真实对话仍依赖 `SILICONFLOW_API_KEY` 等 provider 凭据。关闭 `ORIN_AUTH_SELF_REGISTRATION_ENABLED` 时，注册页会禁用提交并提示联系管理员。

管理端的智能体列表会把该资源标识为“个人默认”，并展示所属用户 ID 与管理提示。默认助手是系统兜底资源，不能在列表里直接删除；管理员可进入智能体控制台调整提示词、运行参数等配置，模型与密钥仍由全局 provider 环境变量控制。若不希望自动生成兜底助手，可设置 `ORIN_AGENT_DEFAULT_PERSONAL_AGENT_ENABLED=false`。

## 4. 第一次使用：最小验证流程

```bash
# 1. 启动三端
./manage.sh start

# 2. 烟测
bash scripts/smoke-test.sh

# 3. 浏览器访问
open http://localhost:5173
```

最小可验证清单：

- [ ] `/`、`/chat`、`/platform` 可打开，无白屏
- [ ] `/register` 可打开；开启自助注册时可创建 `ROLE_USER` 并进入 `/chat`，普通用户至少能看到默认助手入口
- [ ] 登录成功（默认账号由本地配置或初始化向导创建；生产环境不得使用示例密码）
- [ ] `/workspace/agents` 可打开，智能体管理入口可见
- [ ] `/workspace/workflows` 可打开，工作流页面无白屏
- [ ] 管理员访问 `/admin/gateway` 可打开统一网关与全局 API Key；普通用户访问时被拦截

## 5. 联调要点

### 5.1 看接口是否真存在

```bash
# 直接搜后端控制器
rg "@RequestMapping|@GetMapping|@PostMapping" \
   orin-backend/src/main/java/com/adlin/orin

# 或打开 Swagger
open http://localhost:8080/swagger-ui/index.html
```

### 5.2 看页面入口是否还在用

```bash
# 路由常量
sed -n '1,260p' orin-frontend/src/router/routes.js

# 顶部菜单可见性（角色过滤与开关）
sed -n '1,260p' orin-frontend/src/router/topMenuConfig.js

# 找开发中提示或未启用提示
rg "开发中|未启用|待实现" orin-frontend/src
```

### 5.3 看工作流/协作是否真执行

涉及工作流、协作、知识链路时，必须同时核对三层：

1. 前端节点配置和入口页
2. Java 后端控制器与代理层
3. Python `orin-ai-engine/app/engine` 节点处理器与 TaskRuntime

页面可点开 ≠ 能力闭环。

## 6. 文档使用原则

- 路由常量、菜单项、组件文件三者都存在，仍不等于能力闭环
- 部分路径（版本管理、协作配置等）是同页面别名复用
- 模块成熟度请对照 [功能完成度.md](./功能完成度.md)
- 接口字段以 Swagger 与控制器代码为准

## 7. 历史路径与重定向

以下路径来自 `LEGACY_ROUTE_REDIRECTS` 或旧文档，仅用于兼容访问和排查历史链接，不作为当前主导航入口：

| 旧路径示例 | 当前处理口径 |
|------------|--------------|
| `/dashboard/agents/list`、`/dashboard/agents/onboard`、`/dashboard/agents/chat-logs` | 重定向到 `/workspace/agents`、`/workspace/workspace` 或 `/workspace/conversations` 等智能体落地页 |
| `/dashboard/applications/*` | 历史应用路径；重定向到 `/workspace/*` canonical 路径 |
| `/dashboard/knowledge/*`、`/dashboard/resources/*` | 历史知识库路径；重定向到 `/workspace/knowledge/*` |
| `/dashboard/runtime/*` | 历史运行监控路径；重定向到 `/admin/runtime/*`，仅管理员可访问 |
| `/dashboard/control/*` | 历史系统管理路径；重定向到 `/admin/*`，仅管理员可访问 |
| `/dashboard/system/users`、`/dashboard/system/api-keys`、`/dashboard/system/audit-logs` | 旧系统管理路径；分别重定向到 `/admin/users`、`/admin/gateway`、`/admin/audit-logs` 等当前落地页 |
